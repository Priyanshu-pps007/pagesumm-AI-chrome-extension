# 🧠 Chrome Extension: OpenAI Atlas & Comment Assistant

A powerful Chrome extension that brings **OpenAI Atlas** and **Comment Intelligence** right into your browser.  
It intelligently understands the content of your **current webpage** and lets you **interact, ask questions, or get contextual insights** — all without leaving the page.

---

## 🚀 Features

- 🔍 **Page Context Understanding**  
  The extension analyzes your current webpage using OpenAI Atlas intelligence to understand the context and content.

- 💬 **Interactive Querying**  
  Ask natural language questions about what’s on the page — get instant, relevant answers powered by OpenAI.

- 🧩 **Smart Comment Assistant**  
  Generate thoughtful comments or summaries for discussions, blogs, or social media directly from the page.

- ⚡ **Seamless Integration**  
  Works right within your Chrome browser — no need to copy-paste or switch tabs

- 💻 **Works in offline mode**
  It uses gemini nano model for its task that works in offline mode.
  Totally on client side so no internet is required

---

## 🛠️ How It Works

1. **Install the Extension**  
   Add the extension to your Chrome browser.  
   Go to manage extension in chrome click on import and upload the exten folder

2. **Activate on Any Page**  
   Open any webpage and click the extension icon.

3. **Ask or Comment*  
   Use the input box to ask questions or generate contextual comments.

4. **Get Smart Responses**  
   The assistant leverages OpenAI Atlas API to deliver accurate, page-aware responses.
